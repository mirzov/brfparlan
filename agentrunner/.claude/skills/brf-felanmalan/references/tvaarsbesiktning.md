Senast verifierad: 2026-11-01.

## Tidslinje (enligt e-post)

| Tid | Händelse |
|---|---|
| 2024-06-11 | Slutbesiktning av byggnaden |
| Jan 2026 | OBOS skickar information om garantibesiktning. Ola begär status på punkter från slutbesiktningsprotokollet |
| Jan–mar 2026 | Styrelsen förbereder: rundvandring, felrapportering från medlemmar, utskick (HTML-mejl) och möten hos IT-ansvarig |
| Feb 2026 | Offert från oberoende besiktningsman (Pantektor) för omfattande 2-årsbesiktning, vecka 19–20 |
| Vår 2026 | Garantibesiktning genomförs. Fel noteras som anmärkningar (bl.a. E-anmärkningar) |
| Aug–sep 2026 | OBOS föreslår schema för avhjälpande våning för våning. Plan 14 får extra vecka. Styrelsen ställer frågor om schema, tillträde, skydd/städ och dokumentation |
| Okt 2026 | Avhjälpande pågår. Enskilda medlemmar debatterar åtgärdsmetod (t.ex. sprickor/hörnförstärkning) med OBOS/AF Bygg |

## Hur styrelsen arbetar

- Medlemmar ombeds lista fel inför besiktningen. Sprickor i väggar/hörn är vanliga i nyproduktion och kan tas upp direkt med besiktningsmannen.
- Styrelsen kan samla in medgivande om tillträde via formulär. Utan svar antar OBOS att medlemmen själv ger åtkomst.
- Tillträdesproblem ska snabbt meddelas styrelsen så att den kan agera.
- Styrelsen begär protokoll över genomförda avhjälpanden och status på ej avslutade anmärkningar, både till medlem och till föreningen.

## Typiska frågor och svar

| Fråga | Svar |
|---|---|
| "Vem avgör hur felet åtgärdas?" | Entreprenören väljer metod efter felets karaktär, men åtgärden ska vara fackmässig. Medlem kan invända skriftligt till OBOS/AF Bygg |
| "Vad är en E-anmärkning?" | Anmärkning som ska avhjälpas under garantitiden |
| "Kan styrelsen delta vid besök?" | Normalt nej. Den enskilda medlemmen hanterar dialog och tillträde. Styrelsen deltar inte operativt i varje ärende |
| "Fel som rör flera lägenheter" | Styrelsen kan lyfta frågan mot OBOS som övergripande problem om flera medlemmar rapporterat samma fel |
| "Golv ojämna, flytspackel" | Samla uppgifter och skicka till styrelsen inför besiktning. Hänvisa till garantiärende |

## Utkast

- Utkast till OBOS i frågor om tidplan och åtgärder är **styrelsebeslut** (utkast kommer normalt från viceordförande/Ola). Assistenten markerar `[KRÄVER STYRELSEBESLUT]`.
- Boende hänvisas till egen anmälan (se mallen i `brf-svarsstil`).
